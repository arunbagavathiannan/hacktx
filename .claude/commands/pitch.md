description: Write a timed pitch script with demo cues, fallbacks, and Q&A prep
---

Write the pitch script in `pitch/script.md`. Adapted from currenjin/hackathon-kit (MIT).

1. **Ask for the constraints** if they aren't known: total pitch time, whether Q&A is included,
   how long the live demo gets, who presents.
2. **Time budget.** Split the time across hook → problem ("plans die in the GC") → live demo →
   how it works → sponsors → what's next. Include demo loading time and screen switches.
3. **Script table**, one row per beat: start–end time, slide or screen, exact words to say,
   click/tap cue, fallback cue if it fails.
4. **Sentences:** one message per sentence, easy to say out loud, explain jargon once,
   name each sponsor together with what it does in the product. Don't read the slide aloud.
   Only state results the demo actually shows.
5. **Demo cues:** exactly which screen, which chat message triggers the popup, what to say
   while results load, and which screenshot or recording to switch to if it breaks.
6. **Q&A:** the 5 questions judges are most likely to ask (privacy of reading chats, what's
   real vs mocked, how it scales, business model, why Meta/SerpAPI) with 2-sentence answers.
7. **Rehearsal checklist:** run it with real screens twice in a row within time. If it runs
   long, cut sentences, don't talk faster.

Don't commit or push unless asked.
